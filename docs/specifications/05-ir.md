# Especificación: representación intermedia

**Estado:** draft  
**Dependencia:** [semántica](04-semantics.md)  
**Issue:** #14

## Concepto y problema

El AST conserva estructura fuente; ejecutar u optimizar directamente sobre él
repite casos recursivos. La IR linealiza expresiones validadas en instrucciones
con valores temporales para separar significado de estrategia de ejecución.

## Contrato

Una función IR contiene un bloque de entrada y una secuencia de instrucciones:
`Const`, `Load`, `Store`, `Add`, `Subtract`, `Multiply`, `Divide` y `Return`.
Cada instrucción que produce valor recibe un identificador temporal. El lowering
solo acepta AST sin errores semánticos.

## Invariantes

1. Todo operando temporal fue definido antes de usarse.
2. Cada binding cargado fue almacenado previamente.
3. La última instrucción observable del bloque es `Return`.
4. El lowering conserva el orden de evaluación de izquierda a derecha.

## Alternativas y límites

Se adopta un bloque lineal para mostrar dataflow sin CFG complejo. SSA con
phi-nodos y múltiples bloques se difiere hasta que el lenguaje tenga control de
flujo. No hay saltos, funciones ni optimizaciones en esta fase.
